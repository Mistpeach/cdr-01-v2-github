# CDR01 v2 上位机使用手册

## 1. 安装与运行

```bash
cd cdr-01v2/host
pip install -r requirements.txt      # bleak / PySide6 / python-mpv

# 视频同步需要 libmpv（二选一）：
#   a) 安装 mpv 播放器后 pip 装 python-mpv（python-mpv 会找到 mpv-2.dll）
#   b) 或把 libmpv 的 mpv-2.dll 放到本目录/系统 PATH（打包时随包内置）

python -m cdr01v2_host.main
```

> 未检测到 libmpv 时自动进入**纯脚本模式**（CSV 播放照常，只是不能同步视频）。

## 2. 界面

- **连接**：点"连接 CDR01v2"按广播名扫描连接；连接后显示"已连接"，断线自动重连（1/2/4/8/10s 退避）。
- **手动控制**：选目标侧（双侧/左/右）→ 输入命令（如 `POINT 0 0 0 300`）→ 发送；
  快捷按钮（回中/Home/测试圆/随机/STOP）与振动滑杆。
- **脚本 / 视频播放**：载入 CSV、载入视频、播放/暂停/停止、进度条拖动。
- **日志**：实时显示设备响应（带 `[L]`/`[R]` 标签）与发送记录。

## 3. CSV 脚本格式（原作者格式，直接兼容）

```
时间ms,左命令,右命令
77976,,REPEAT_CIRCLE 0 0 -85 100 5000
78023,REPEAT_CIRCLE 0 0 -85 100 5000,
151882,STOP,STOP
```

- 无表头，恰好 3 列，第 4 列起忽略；UTF-8（容忍 BOM）。
- 第 1 列 = 整数毫秒（升序）；第 2/3 列 = 左右两侧命令文本。
- **空单元格 = 该侧不动作**（保持当前动作，REPEAT 持续）。
- 左列 → 左侧（L0-L2），右列 → 右侧（R0-R2），单连接内按帧 SIDE 字段分侧下发。

## 4. 视频同步

1. 点"载入视频"选媒体文件；若同目录存在同名 `.csv` 会自动加载脚本。
2. 点"播放"：视频与脚本同时开始，脚本以**视频时间轴**为时钟逐条下发（10ms tick）。
3. 暂停/停止/拖动进度条：视频与脚本联动；拖动跨度大时自动补发两侧最近命令保持姿态连续。
4. 脚本事件结束 → 自动 `STOP` 并暂停视频。

## 5. 左右独立控制

- 手动：目标侧选"左"/"右"，命令只驱动对应侧。
- 脚本：CSV 左/右两列天然分侧（`SIDE=0x01/0x02` 帧）。
- 双侧同步：目标侧选"双侧"或发送 `SIDE=0x00` 帧。

## 6. 常见问题

| 现象 | 处理 |
| --- | --- |
| 扫描不到 `CDR01v2` | 确认固件已烧 v2 版本；串口看 `BLE advertising started (CDR01v2)`；靠近重扫 |
| 连上但命令没反应 | 看日志有无 `[发送失败]`；确认固件串口有 `Received Command` 输出 |
| 日志出现 `EVT 帧解析失败: CRC 校验失败` | 协议版本不一致（固件/上位机 CRC 实现不同步）；重新烧录同版本固件 |
| 视频加载后黑屏 | 未装 libmpv/mpv-2.dll；看"视频："标签是否提示未检测到 mpv |
| 播放脚本动作慢半拍 | 正常（命令下发 + 舵机 10ms 节拍）；脚本事件间隔 ≥50ms 效果最佳 |

## 7. 打包（交付 exe）

```bash
pip install pyinstaller
# 把 mpv-2.dll 放到与 .exe 同目录或 --add-binary 进去
pyinstaller --onefile --windowed --name CDR01v2 \
    --add-binary "mpv-2.dll;." \
    -m cdr01v2_host.main
```
