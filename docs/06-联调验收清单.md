# CDR01 v2 联调验收清单

> 用于 P5 联调与最终交付验收。逐项打勾；每项附验证方法。

## A. 硬件与供电（装机前）

- [ ] A1 GPIO15/16 所在板背无 32kHz 晶振（有则已换脚改 `config.h`）。
- [ ] A2 6 舵机信号线对应 GPIO 表：L0=4、L1=5、L2=15、R0=16、R1=17、R2=18。
- [ ] A3 舵机 VCC 全部接外部 5V 正极、GND 接外部负极，与开发板**单点共地**。
- [ ] A4 1000µF 在电源进线端，每舵机 VCC-GND 并联 1µF。

## B. 固件上电自检

- [ ] B1 串口 115200 打印 `Setup complete`，且 `[SELF TEST] Servo LEDC ready: 6ch`。
- [ ] B2 上电 6 舵机回中（90°/1500µs）锁定。
- [ ] B3 `VERSION` → `VALUE version CDR01v2 firmware 0.1.0`。
- [ ] B4 `JOINT 90 90 90 200` → `[L] OK JOINT started` + `[R] OK JOINT started`。

## C. 逐通道验证（串口 `L:`/`R:` 前缀）

- [ ] C1 `L:JOINT 60 90 90 400` 仅左臂0（GPIO4）动。
- [ ] C2 `L:JOINT 90 60 90 400` 仅左臂1（GPIO5）动。
- [ ] C3 `L:JOINT 90 90 60 400` 仅左臂2（GPIO15）动。
- [ ] C4 `R:JOINT 60 90 90 400` 仅右臂0（GPIO16）动。
- [ ] C5 `R:JOINT 90 60 90 400` 仅右臂1（GPIO17）动。
- [ ] C6 `R:JOINT 90 90 60 400` 仅右臂2（GPIO18）动。
- [ ] C7 6 通道方向一致；方向反的已改 `SERVO_INVERT`。

## D. BLE 协议（nRF Connect 或上位机）

- [ ] D1 扫描可见 `CDR01v2` + 服务 `b4a00001-...`。
- [ ] D2 写 CMD 帧（规范 §7 测试向量）→ 对应侧动作、EVT 回 `[L]/[R] OK...`。
- [ ] D3 每秒收到心跳帧 `CD 01 02 02 00 48 42 04 54`。
- [ ] D4 故意写错 CRC → EVT 回 `ERR CRC`，且后续正常帧仍可执行（重同步）。

## E. 上位机功能

- [ ] E1 连接/断开/自动重连正常，状态显示正确，心跳绿点（连接 3s 无心跳告警）。
- [ ] E2 手动面板：双侧/左/右命令均驱动正确侧；振动滑杆有效。
- [ ] E3 载入原作者 `示例脚本csv/1.csv` 完整播放，左右列作用于对应侧，无丢事件。
- [ ] E4 暂停/停止即时生效；拖动进度条后姿态连续（跨度大时补发两侧最近命令）。
- [ ] E5 载入视频 + 同名 CSV 自动加载；播放/暂停/Seek 视频与脚本联动；结束自动 STOP。

## F. 轨迹一致性核对（与原版对齐）

- [ ] F1 用同一命令序列分别烧 v1 与 v2 固件，串口 `Target Angles` 输出逐条一致。
- [ ] F2 抽样 ≥10 条命令（POINT/LINE/JOINT/CIRCLE/REPEAT_LINE/REPEAT_TRIANGLE/
        REPEAT_CIRCLE/LISSAJOUS/ROSE/REPEAT_POINT）两端角度序列一致。
- [ ] F3 REPEAT_* 的 Approach（15% 时长、100~1000ms 钳位）行为一致。

## G. 压力与安全

- [ ] G1 50 事件/秒 Burst 无丢帧、无 `ERR FRAME`/`ERR CRC`（除非人为构造）。
- [ ] G2 `STOP` 立即停止并保持位置；`DSTOP` 生效。
- [ ] G3 断开 BLE 后（默认）动作继续；`SAFETY_STOP_ON_BLE_DISCONNECT=true` 时断开即停。
- [ ] G4 长时间连续播放无复位、无舵机过热啸叫。

## H. 交付物

- [ ] H1 `cdr-01v2/firmware` 可编译、`firmware.bin` 生成（已通过）。
- [ ] H2 `cdr-01v2/host` 逻辑自测 5/5 通过（`python tests/run_tests.py`）。
- [ ] H3 三份文档齐全：`00-技术栈与开发计划`、`01-通信协议规范`、`02-上位机使用手册`、`03-固件烧录与排障`、`04-联调验收清单`（本文）。
- [ ] H4 PyInstaller 打包 exe（含 libmpv）在干净机器可运行。

> 备注：F/G 需实机 + 逻辑分析仪/双机对照；A~E 是首发必过项。
