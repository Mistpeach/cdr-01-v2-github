# CDR01 v2 通信协议完全规范（v2.0）

> 状态：**定稿**，与固件 `CDR01v2 0.1.0`、上位机 `cdr01v2_host` 同步。
> 本文档是 v2 上下位机通信的**唯一权威定义**：传输层 → 帧层 → 命令语法 → T-Code → 响应/错误 → 时序 → 应用层 CSV。
> 早期 P1 冻结版（v1.0）仅包含传输与帧定义，已被本文档取代（帧格式未变，内容扩充）。

---

## 1. 总览

### 1.1 角色与拓扑

```
┌──────────────┐   单条 BLE 连接（GATT）    ┌────────────────────┐
│  上位机       │  ── CMD 特征（写）──────►  │  ESP32-S3 固件      │
│ (PC/PySide6) │  ◄── EVT 特征（通知/读）──  │  CDR01v2            │
└──────────────┘                            └────────────────────┘
                    串口（USB-UART 桥）为独立调试通道，非本协议
```

- **一条 BLE 连接**承载左右两侧全部指令：命令帧内用 `SIDE` 字段区分「双侧 / 左 / 右」。
- 下位机为 GATT Server，上位机为 Client；一主一从，v1.0 只支持 1 台设备对 1 个上位机。
- 协议为**文本命令语义 + 二进制帧封装**：payload 是原作者命令集的 ASCII 文本，外层加帧头与 CRC。

### 1.2 协议分层

| 层 | 内容 | 章节 |
| --- | --- | --- |
| 传输层 | BLE GATT（服务/特征/属性/MTU）、串口调试通道 | §2 |
| 帧层 | 帧结构、字段、CRC16、分片与重同步 | §3 |
| 命令层 | payload 语法：坐标/单位、全部命令、侧路由 | §4 |
| T-Code 层 | T-Code v0.3 子集语法与轴映射 | §5 |
| 响应层 | OK / ERR / VALUE、错误码、心跳、READY | §6 |
| 时序层 | 连接建立、命令抢占、播放节拍、断线重连 | §7 |
| 应用层 | 原作者 CSV 脚本格式与帧映射 | §8 |

### 1.3 术语

| 术语 | 含义 |
| --- | --- |
| 侧 / SIDE | 逻辑侧：`0`=双侧、`1`=左侧（L0-L2）、`2`=右侧（R0-R2） |
| 通道 | 物理舵机输出：L0/L1/L2=GPIO4/5/15，R0/R1/R2=GPIO16/17/18 |
| 引擎 | 单侧 delta 运动引擎（左侧、右侧各一个独立实例） |
| 百分比坐标 | 以 `workspaceRadius/Height` 为基准的 -100..100 坐标（见 §4.2） |
| 命令 | 一条 ASCII 文本，如 `POINT 0 0 0 300` |
| 帧 | 封装一条命令的二进制报文（§3） |

## 2. 传输层

### 2.1 BLE（主通道）

| 项 | 值 |
| --- | --- |
| 广播名 | `CDR01v2`（精确匹配） |
| 服务 UUID | `b4a00001-3f21-4c8e-9d5a-6b7e0f1a2c3d` |
| **CMD** 特征 | `b4a00002-3f21-4c8e-9d5a-6b7e0f1a2c3d`，属性 `Write` + `Write Without Response` |
| **EVT** 特征 | `b4a00003-3f21-4c8e-9d5a-6b7e0f1a2c3d`，属性 `Read` + `Notify` |
| 电池服务 | `0x180F` / `0x2A19`（Read + Notify，uint8 0-100） |
| 本地 MTU | 固件设为 517；实际大小由 OS/BLE 栈在连接时协商（Windows 通常 247） |
| 广播内容 | 服务 UUID + 名称（Scan Response 打开） |

**连接行为**

1. 下位机上电后广播 `CDR01v2`。
2. 上位机连接、订阅 EVT（CCCD 0x2902 写 0x0001）。
3. 连接建立后下位机发送一条 EVT 响应 `READY`（payload 文本 `READY`）。
4. 连接期间下位机每 **1000ms** 发一条心跳 `HB`。
5. 断开后下位机**重新广播**；上位机按 1/2/4/8/10s 退避自动重连。

> EVT 的 `Read` 返回**最近一帧事件的二进制字节**（不是文本），便于调试；正常上位机用 Notify。

### 2.2 串口（调试通道，非本协议）

| 项 | 值 |
| --- | --- |
| 波特率 | 115200 8-N-1 |
| 物理口 | 板载 USB-UART 桥（CH343 等），**不是** USB CDC |
| 命令格式 | 行文本，`\n` 结尾；无需帧头/CRC |
| 侧路由 | 行首前缀 `L:` 或 `R:`（例 `L:POINT 0 0 0 300`）；无前缀=双侧 |
| 回显 | 非 T-Code 行原样回显；响应同时打印 |
| 额外输出 | 启动横幅 `[BOOT]`、自检、`Target Angles`、`Vibrating` 等调试信息 |

> 串口与 BLE 可**同时**使用：BLE 发命令、串口看日志/发调试命令，互不冲突。

## 3. 帧层

### 3.1 帧结构

```
偏移   0     1     2       3       4         5 .. 5+LEN-1        5+LEN .. 6+LEN
      0xCD  0x01  FIELD   LEN_LO  LEN_HI    payload[LEN]         CRC16（小端）
       └────┬────┘ └──┬──┘ └──────┬──────┘  └──────┬──────┘       └────┬────┘
          magic    FIELD        LEN(2B LE)       payload           CRC(2B LE)
总长 = 7 + LEN
```

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| `magic` | 2B | 固定 `0xCD 0x01` |
| `FIELD` | 1B | CMD 帧 = `SIDE`；EVT 帧 = `TYPE` |
| `LEN` | 2B 小端 | payload 字节数，**1..240** |
| `payload` | LEN | ASCII 命令文本（CMD）或响应文本（EVT） |
| `CRC16` | 2B 小端 | CRC-16/CCITT-FALSE，范围 = `FIELD+LEN+payload`（共 3+LEN 字节） |

**硬性规则**

- 一帧 = 一条命令（CMD）/ 一条事件（EVT）；不跨帧拼命令。
- payload 不允许包含 NUL；建议纯 ASCII。总帧长上限 **247 字节**。
- 帧内不需要换行符；首尾空白由固件 `trim()`。
- 同一连接可连续写多帧，固件按流式解析。

### 3.2 CRC-16/CCITT-FALSE

| 参数 | 值 |
| --- | --- |
| 多项式 | `0x1021` |
| 初值 | `0xFFFF` |
| 输入/输出反转 | 否 |
| 结果异或 | 否 |
| 计算范围 | `FIELD` + `LEN`(2B) + `payload` |

```python
def crc16(data: bytes) -> int:
    c = 0xFFFF
    for b in data:
        c ^= b << 8
        for _ in range(8):
            c = ((c << 1) ^ 0x1021) & 0xFFFF if c & 0x8000 else (c << 1) & 0xFFFF
    return c
```

### 3.3 CMD 帧（上位机 → 下位机）

| SIDE | 含义 | 等价串口写法 |
| --- | --- | --- |
| `0x00` | 双侧（左右同步） | 无前缀 |
| `0x01` | 仅左侧 | `L:` 前缀 |
| `0x02` | 仅右侧 | `R:` 前缀 |

payload = §4 中的命令文本（不含侧前缀；若 payload 里带了 `L:`/`R:` 也会被识别并覆盖 SIDE）。

### 3.4 EVT 帧（下位机 → 上位机）

| TYPE | payload | 触发 |
| --- | --- | --- |
| `0x01` 响应 | `READY` / `OK ...` / `ERR ...` / `VALUE ...` | 连接建立时一次；每条命令执行后 |
| `0x02` 心跳 | `HB` | 连接期间每 1000ms 一次 |

### 3.5 解析与重同步（下位机侧）

接收缓冲 520B，滑动解析：

1. 找帧头 `CD 01`；找不到则丢 1 字节继续找。
2. 帧头后不足 4 字节（FIELD+LEN）→ 等待更多数据。
3. `LEN==0` 或 `LEN>240` → 丢 2 字节帧头重同步，回 `ERR FRAME`。
4. 收满 `7+LEN` 字节 → 校验 CRC：
   - 通过 → 按 SIDE 分发执行；
   - 失败 → 回 `ERR CRC`，丢 2 字节帧头重同步。

> 上位机侧无需重同步（每次 Notify 都是完整一帧）。

### 3.6 测试向量（双端单测共用）

| 说明 | 帧（hex） |
| --- | --- |
| 双侧 `STOP` | `CD 01 00 04 00 53 54 4F 50 81 DC` |
| 左侧 `POINT 0 0 0 300` | `CD 01 01 0F 00 50 4F 49 4E 54 20 30 20 30 20 30 20 33 30 30 94 43` |
| 右侧 `REPEAT_LINE -50 0 -25 50 0 -25 700` | `CD 01 02 22 00 52 45 50 45 41 54 5F 4C 49 4E 45 20 2D 35 30 20 30 20 2D 32 35 20 35 30 20 30 20 2D 32 35 20 37 30 30 30 11` |
| 心跳 `HB` | `CD 01 02 02 00 48 42 04 54` |
| 响应 `[L] OK POINT started` | `CD 01 01 14 00 5B 4C 5D 20 4F 4B 20 50 4F 49 4E 54 20 73 74 61 72 74 65 64 B2 14` |

## 4. 命令层（payload 语法）

### 4.1 通用语法规则

```
command   := NAME (SP arg)*
NAME      := 大写命令名（大小写敏感）
arg       := 十进制数字，可带正负号/小数点
SP        := 一个或多个空格/制表符
```

| 规则 | 说明 |
| --- | --- |
| 编码 | ASCII（UTF-8 兼容）；不允许 NUL |
| 行长 | payload ≤ 240 字节（含命令名与空格） |
| 空白 | 命令名与参数之间、参数之间允许任意多个空格；首尾空白忽略 |
| 大小写 | 命令名区分大小写（必须大写）；T-Code 轴字母不区分；`LED_MODE` 的值不区分 |
| 数字 | 浮点 `-1.25`、`+3`、`0`；整数参数（`ms`、`VIBRATE` 百分比）按整数解析 |
| 参数个数 | 必须精确匹配；多/少参数 → `ERR INVALID_COMMAND` |
| 未知命令 | → `ERR INVALID_COMMAND Invalid UNKNOWN command` |
| 侧前缀 | 串口可用 `L:`/`R:`；BLE 用 SIDE 字段（payload 内带前缀亦可） |

### 4.2 坐标与单位

| 符号 | 含义 | 换算 |
| --- | --- | --- |
| `x y z` | 末端直交坐标，百分比 | `act = home + pct/100 × 范围`：x/y 基准 `workspaceRadius=20mm`，z 基准 `workspaceHeight=15mm`，home=(0,0,-33) |
| `cx cy cz` | 圆/曲线中心，百分比 | 同上 |
| `r` | 半径，百分比 | `r_act = r/100 × 20mm`；**负值反转圆周方向** |
| `motion_ms` / `move_ms` | 动作时间，毫秒 | 步数 = `max(1, ms/10)`，10ms 一节拍 |
| `wait*_ms` | 到达点后的停顿，毫秒 | 省略=0 |
| `nx ny nz` | CIRCLE3D 平面法线 | 内部归一化；零向量非法 |
| `ax ay az` | LISSAJOUS 振幅 | ax/ay 半径基准，az 高度基准 |
| `fx fy fz` | LISSAJOUS 频率倍率 | 浮点 |
| `phase_y phase_z` | LISSAJOUS 相位（度） | X 相位固定 0 |
| `petals` | ROSE 花瓣系数 | 建议 3/4/5 |
| `percent` | 百分比 | VIBRATE/LED_BRIGHTNESS：0-100 |

**工作空间校验**：`√(dx²+dy²) ≤ 20.1mm` 且 `|dz| ≤ 15.1mm`，越界回 `ERR WORKSPACE`。

### 4.3 命令总表

| 命令 | 参数个数 | 作用 | 响应 |
| --- | --- | --- | --- |
| `POINT x y z ms` | 4 | 直交目标，关节空间插值 | `OK POINT started` |
| `LINE x y z ms` | 4 | 当前点→目标，直交直线插值 | `OK LINE started` |
| `JOINT a1 a2 a3 ms` | 4 | 直接给 3 个舵机角度 | `OK JOINT started` |
| `CIRCLE cx cy cz r ms` | 5 | XY 圆 1 周 | `OK CIRCLE started` |
| `CIRCLE3D cx cy cz nx ny nz r ms` | 8 | 任意平面圆 1 周 | `OK CIRCLE3D started` |
| `LISSAJOUS cx cy cz ax ay az fx fy fz py pz ms` | 12 | 利萨茹 1 周期 | `OK LISSAJOUS started` |
| `ROSE cx cy cz r petals ms` | 6 | 玫瑰线 1 周期 | `OK ROSE started` |
| `REPEAT_POINT x1 y1 z1 x2 y2 z2 ms [w1 w2]` | 7 或 9 | 两点关节插值往复 | `OK REPEAT_POINT started` |
| `REPEAT_LINE ...` | 7 或 9 | 两点直线往复 | `OK REPEAT_LINE started` |
| `REPEAT_TRIANGLE x1..z3 ms [w1 w2 w3]` | 10 或 13 | 三角形周回 | `OK REPEAT_TRIANGLE started` |
| `REPEAT_CIRCLE cx cy cz r ms` | 5 | 圆无限循环 | `OK REPEAT_CIRCLE started` |
| `REPEAT_CIRCLE3D cx cy cz nx ny nz r ms` | 8 | 任意平面圆循环 | `OK REPEAT_CIRCLE3D started` |
| `REPEAT_LISSAJOUS ...` | 12 | 利萨茹循环 | `OK REPEAT_LISSAJOUS started` |
| `REPEAT_ROSE cx cy cz r petals ms` | 6 | 玫瑰线循环 | `OK REPEAT_ROSE started` |
| `REPEAT_RANDOM` | 0 | 内置随机动作 | `OK REPEAT_RANDOM started` |
| `VIBRATE percent` | 1 | 振动电机 0-100% | `OK VIBRATE set` |
| `BATTERY` | 0 | 读电量（不清除动作） | `VALUE battery ...` |
| `STOP` | 0 | 停止并清 REPEAT/随机 | `OK STOP` / `OK [L] STOP` |
| `VERSION` | 0 | 固件版本 | `VALUE version ...` |
| `TCODE_AXIS ...` | 5/6 | T-Code 轴槽位配置 | `OK TCODE_AXIS set` |
| `TCODE_STATUS` | 0 | 6 槽位状态 | `VALUE tcode ...` |
| `TCODE_SAVE` / `TCODE_RESET` | 0 | 保存/复位轴配置 | `OK ...` |
| `TCODE_DEBUG ON\|OFF` | 1 | 调试输出开关 | `OK TCODE_DEBUG ...` |
| `LED_STATUS` | 0 | LED 状态 | `VALUE led ...` |
| `LED_BRIGHTNESS percent` | 1 | LED 亮度 0-100 | `OK LED_BRIGHTNESS set` |
| `LED_MODE auto\|dim\|off` | 1 | LED 模式 | `OK LED_MODE set` |
| `LED_TEST` | 0 | LED 自检 | `OK LED_TEST started` |

> 表中"响应"列给出的是去掉标签的形式。**运动类命令的响应由左/右引擎分别发出，带 `[L]`/`[R]` 标签**（双侧命令会收到两条）；全局命令（STOP/VERSION/BATTERY/LED/TCODE）不带标签。

### 4.4 逐条命令

#### 4.4.1 `POINT x y z motion_ms`
直交目标经 IK 后，在**关节空间**线性插值。
- 示例：`POINT 0 0 0 300`、`POINT 50 0 -25 500`
- 错误：`ERR WORKSPACE`（目标越界）、`ERR IK`（无解）

#### 4.4.2 `LINE x y z motion_ms`
从当前直交位置到目标做**笛卡尔直线插值**；当前位置未知时 `ERR POSITION_UNKNOWN`。
- 启动后已执行过回中/POINT/JOINT，当前位置已知，可直接用。

#### 4.4.3 `JOINT a1 a2 a3 motion_ms`
直接指定三个舵机角度（度，输出时钳位到 0..180）；完成后用正运动学尝试更新"当前位置"。
- 示例：`JOINT 90 90 90 200`（中位）

#### 4.4.4 `CIRCLE cx cy cz r motion_ms`
XY 平面整圆；`r<0` 反向。开始前若当前点距起点 >0.5mm，先做 Approach（时长 = 15% 动作时间，钳位 100..1000ms）。

#### 4.4.5 `CIRCLE3D cx cy cz nx ny nz r motion_ms`
法线定义平面上的整圆；法线零向量 → `ERR INVALID_ARGUMENT`。

#### 4.4.6 `LISSAJOUS cx cy cz ax ay az fx fy fz py pz motion_ms`
三轴利萨茹曲线，1 周期。

#### 4.4.7 `ROSE cx cy cz r petals motion_ms`
XY 平面玫瑰线，1 周期。

#### 4.4.8 `REPEAT_POINT x1 y1 z1 x2 y2 z2 move_ms [w1 w2]`
两点往复；`w1/w2` 为到达点 1/点 2 后停顿。当前位置未知时先以 `move_ms` 关节点移动至 P1。

#### 4.4.9 `REPEAT_LINE ...`
同上但为直交直线往复；当前位置未知 → `ERR POSITION_UNKNOWN`。

#### 4.4.10 `REPEAT_TRIANGLE x1..z3 move_ms [w1 w2 w3]`
P1→P2→P3→P1… 周回，各边直线插值；逆时针/顺时针由顶点顺序决定。开始前校验三点可达。

#### 4.4.11 `REPEAT_CIRCLE / REPEAT_CIRCLE3D / REPEAT_LISSAJOUS / REPEAT_ROSE`
无限循环，参数同非 REPEAT 版本。

#### 4.4.12 `REPEAT_RANDOM`
从内置弱档（11 条）或强档（10 条）预设中每 5~20s 随机切换一条执行；按键可切换档位。

#### 4.4.13 `VIBRATE percent`
振动电机百分比（越界钳位）；单电机，两侧共享。

#### 4.4.14 `BATTERY`
返回并通知电量；**不会清除当前动作**（唯一例外命令）。
```
VALUE battery voltage=5.00,current=0.10,level=100
```

#### 4.4.15 `STOP`
停止动作、清除 REPEAT/随机、LED 回 Idle；舵机保持最后位置。SIDE=0 停双侧；SIDE=1/2 只停单侧。

#### 4.4.16 `VERSION`
```
VALUE version CDR01v2 firmware 0.1.0
```

#### 4.4.17 `TCODE_AXIS slot axis_id X|Y|Z invert min max`
| 参数 | 说明 |
| --- | --- |
| `slot` | `0`..`5`（0-2 左侧，3-5 右侧） |
| `axis_id` | 字母+数字，如 `L0`、`L3`、`A0`、`Z9`（大小写不敏感，保存为大写） |
| `X|Y|Z` | 映射到的直交轴 |
| `invert` | `0`/`1` |
| `min max` | 百分比范围（-100..100） |

兼容旧格式：`TCODE_AXIS L0 X 0 -100 100`（= 槽位取轴号数字，仅 0..2）。
- 示例：`TCODE_AXIS 3 L3 X 0 -100 100`（右侧槽位改配 L3）

#### 4.4.18 `TCODE_STATUS` / `TCODE_SAVE` / `TCODE_RESET` / `TCODE_DEBUG ON|OFF`
```
VALUE tcode 0:L0=X:norm:-100.0..100.0 1:L1=Z:norm:-100.0..100.0 2:L2=Y:norm:-100.0..100.0
            3:L0=X:norm:-100.0..100.0 4:L1=Z:norm:-100.0..100.0 5:L2=Y:norm:-100.0..100.0
```
（实际响应为单行，空格分隔 6 个槽位）

#### 4.4.19 `LED_STATUS` / `LED_BRIGHTNESS percent` / `LED_MODE auto|dim|off` / `LED_TEST`
```
VALUE led reason=idle,mode=auto,brightness=100,base=idle,battery=normal,level=100,
           voltage=5.00,current=0.10,ble=connected
```

#### 4.4.20 已移除命令（v2 不再支持）
`WIFI` / `WIFI_SAVE` / `WIFI_STATUS` / `WIFI_FORGET` / `WIFI_STOP` /
`HOSTNAME` / `HOSTNAME_SAVE` / `HOSTNAME_RESET` → 均返回 `ERR INVALID_COMMAND Invalid UNKNOWN command`。

### 4.5 侧路由规则

| 入口 | 侧信息 | 规则 |
| --- | --- | --- |
| BLE CMD 帧 | `SIDE` 字段 | 0 双侧 / 1 左 / 2 右 |
| 串口文本 | 行首 `L:` / `R:` | 无前缀=双侧；前缀优先于默认 |
| T-Code 行（任意入口） | **忽略 SIDE** | 由 T-Code 轴槽位决定驱动哪一侧 |

**命令抢占语义**：除 `BATTERY` 外，新命令先停止**被命令目标侧**当前动作（REPEAT/随机/轨迹），再执行；另一侧不受影响。`STOP` 遵循同样规则（SIDE=0 停双侧）。

## 5. T-Code 子协议

payload 若以 T-Code 形式出现（`looksLikeTCodeCommand`：`$`、`D`+数字/`DSTOP`、或「字母+数字」开头），按 T-Code 解析；否则按 §4 命令解析。

### 5.1 行语法

```
line   := token (SP token)*
token  := axis | device
axis   := ALPHA DIGIT DIGIT* [ 'I' DIGIT+ ] [ 'S' DIGIT+ ]
device := '$' | 'D' DIGIT* | 'DSTOP'
```

| 形式 | 含义 |
| --- | --- |
| `L0` | 轴 L 通道 0，值 0.0 |
| `L099` | 轴 L0，值 0.99（轴号后数字为小数部分；≥1 钳位为 0.9999） |
| `L099I500` | 同上，500ms 内到达（区间） |
| `L099S5` | 同上，速度 5（=0.5/100ms → 5/s，内部 ×10 换算） |
| `V050` | 振动通道 0，值 0.50 |
| `DSTOP` | T-Code 急停 |
| `D0` / `D1` / `D2` | 设备信息 / T-Code 版本 / 轴能力 |
| `$` | 保存类 token（回 `OK`） |

### 5.2 轴映射（6 槽位）

| 槽位 | 默认轴 | 映射到 | 说明 |
| --- | --- | --- | --- |
| 0 | `L0` | X（-100..100） | 左侧 |
| 1 | `L1` | Z | 左侧 |
| 2 | `L2` | Y | 左侧 |
| 3 | `L0` | X | 右侧（默认与左侧同轴=镜像） |
| 4 | `L1` | Z | 右侧 |
| 5 | `L2` | Y | 右侧 |

- **镜像用法**：保持默认，一个 UDP/BLE 流中 `L0-L2` 同时驱动两侧。
- **分轴用法**：把右侧槽位改配为 `L3/L4/L5`（`TCODE_AXIS 3 L3 X ...` 等），则 `L0-L2` 只驱动左侧、`L3-L5` 只驱动右侧。
- 未映射的轴 token 被忽略。

### 5.3 时间与速度

| 情形 | 行为 |
| --- | --- |
| 带 `I<ms>` | 移动时间 = 该值（钳位 10..5000ms） |
| 带 `S<v>` | 时间 = 距离 / (v×10/s) × 1000（钳位 10..5000ms） |
| 都不带 | 默认 50ms |
| 多轴同帧 | 取各轴时间的**最大值**作为本帧移动时间 |

### 5.4 设备命令

| 命令 | 响应 |
| --- | --- |
| `D0` | `CDR01v2 firmware 0.1.0` |
| `D1` | `TCode v0.3` |
| `D2` | `L0-0000-9999 L1-0000-9999 L2-0000-9999 L0-0000-9999 L1-0000-9999 L2-0000-9999 V0-0000-9999` |
| `DSTOP` | `OK DSTOP`，停止两侧 T-Code Live 与振动 |

### 5.5 超时

T-Code Live 模式：连续 **750ms** 未收到任何 T-Code 数据 → 停止两侧 Live 运动、振动归 0（`lastTCodeReceiveTime` 复位）。

### 5.6 示例

```
L050 L125 L275I500      # 左右两侧同时到 (X=50%, Z=25%, Y=75%)，500ms
L050 L125 L275 L350 L475 L575I500   # 分轴模式：左侧 L0-L2、右侧 L3-L5
DSTOP                   # 急停
```

## 6. 响应与错误

### 6.1 响应格式

| 形式 | 说明 |
| --- | --- |
| `READY` | 连接建立后一次性（EVT 响应） |
| `OK <message>` | 命令已接受/执行 |
| `ERR <CODE> <message>` | 命令被拒绝或执行中失败 |
| `VALUE <key> <value>` | 查询结果（VERSION/BATTERY/LED/TCODE） |

### 6.2 引擎响应标签

| 来源 | 格式 | 示例 |
| --- | --- | --- |
| 单侧引擎（运动类命令） | `OK [L] ...` / `OK [R] ...` | `[L] OK POINT started`、`[R] OK JOINT started` |
| 全局（STOP/VERSION/BATTERY/LED/TCODE） | 不带标签 | `OK STOP`、`VALUE version ...` |
| 双侧命令 | 两条引擎响应（先 L 后 R） | `[L] OK CIRCLE started` + `[R] OK CIRCLE started` |

> 上位机**不依赖**响应做流控（发完即走）；响应仅用于日志/调试/错误感知。

### 6.3 错误码总表

| CODE | 触发条件 | 处理建议 |
| --- | --- | --- |
| `INVALID_COMMAND` | 命令名未知或参数个数不符 | 检查拼写/参数个数（§4.3） |
| `INVALID_TCODE` | T-Code 行语法错误 | 检查 token 格式（§5.1） |
| `INVALID_TCODE_AXIS` | TCODE_AXIS 参数非法（槽位/轴/范围） | 见 §4.4.17 |
| `INVALID_LED` | LED 参数非法 | 0-100 / auto\|dim\|off |
| `INVALID_ARGUMENT` | 如 CIRCLE3D 法线为零向量 | 修正参数 |
| `UNSUPPORTED_TCODE_DEVICE_COMMAND` | D 编号不支持 | 仅 D0/D1/D2 |
| `POSITION_UNKNOWN` | 需要当前位置但尚未建立 | 先发 `POINT 0 0 0 300` 或 `JOINT` |
| `WORKSPACE` | 目标/轨迹越出工作空间 | 检查坐标范围 |
| `IK` | 逆运动学无解 | 目标不可达 |
| `TRAJECTORY` | 轨迹采样失败 | 检查曲线参数 |
| `INVALID_REPEAT` | 重复命令内部解析失败 | 检查参数 |
| `ERR CRC`（传输层） | 帧 CRC 校验失败 | 丢弃该帧，检查线路/上位机实现 |
| `ERR FRAME`（传输层） | 帧结构非法（LEN=0/超长/缓冲溢出） | 检查帧格式 |

### 6.4 心跳与链路健康

- 连接期间每 1000ms 一条 `HB`。
- 上位机 3s 未收到任何 EVT（含 HB）→ 提示链路异常。
- 断线后下位机自动重新广播；上位机自动重连。

## 7. 交互时序与约束

### 7.1 连接建立时序

```
Host                         Device
 │── BLE connect ───────────►│
 │── CCCD(0x2902)=0x0001 ───►│  (订阅 EVT)
 │◄── EVT: READY ────────────│
 │◄── EVT: HB (每 1s) ───────│
 │── CMD 帧 ────────────────►│
 │◄── EVT: OK/ERR/VALUE ─────│
```

### 7.2 命令执行模型

- **非阻塞**：固件收到帧后立即返回，不等动作完成；上位机发完即走，不等待 ACK。
- **抢占**：新命令先停止目标侧当前动作（REPEAT/随机/轨迹）。
- **10ms 节拍**：运动插值以 10ms 为步进；`steps = max(1, ms/10)`。
- **带宽**：单连接内每帧独立；事件密集时由上位机按时间戳顺序下发，固件按 10ms 节拍消化。

### 7.3 播放时序（上位机）

| 项 | 规则 |
| --- | --- |
| 调度 | 10ms tick；每个 tick 取出所有到期事件 |
| 左列 | 映射为 `SIDE=0x01` 帧 |
| 右列 | 映射为 `SIDE=0x02` 帧 |
| 同 tick 左右事件 | 先左后右连续发两帧 |
| 暂停/停止 | 发 `SIDE=0x00` + `STOP` |
| Seek | 重新定位；跨度 >1200ms 时补发两侧最近一条命令保持姿态连续 |

### 7.4 断线与重连

- 下位机：断开即重新广播（默认**不**急停；`config.h` 的 `SAFETY_STOP_ON_BLE_DISCONNECT` 可改为断开急停）。
- 上位机：退避 1/2/4/8/10s 重连，恢复后继续。

### 7.5 安全相关

| 场景 | 行为 |
| --- | --- |
| `STOP` / `DSTOP` | 立即停止，舵机保持最后位置 |
| 新命令 | 抢占目标侧动作 |
| T-Code 断流 750ms | 自动停止 Live 运动、振动归 0 |
| 目标越界 / IK 无解 | 拒绝执行并回错误 |
| 断开 BLE | 默认继续动作；可配置为急停 |
| 角度越界 | 软限位钳位（`SERVO_ANGLE_MIN/MAX`，默认 0..180） |

## 8. 应用层：CSV 脚本格式

上位机可直接播放原作者格式脚本（**无需转换**）。

```
时间ms,左命令,右命令
77976,,REPEAT_CIRCLE 0 0 -85 100 5000
78023,REPEAT_CIRCLE 0 0 -85 100 5000,
151882,STOP,STOP
```

| 规则 | 说明 |
| --- | --- |
| 列 | 恰好 3 列：`时间ms,左命令,右命令`；第 4 列起忽略 |
| 表头 | 无 |
| 时间 | 整数毫秒，升序（允许相等）；导入时按时间排序 |
| 单元格 | 空 = 该侧不动作（保持当前动作，REPEAT 继续） |
| 编码 | UTF-8（容忍 BOM）；RFC4180 引号转义 |
| 映射 | 左列 → `SIDE=0x01` 帧；右列 → `SIDE=0x02` 帧 |
| `STOP` 单元格 | 按普通命令执行（SIDE=0 停双侧时请把 STOP 放在左右两列或使用单侧 STOP 语义） |

## 10. 完整示例会话（实机抓取）

```
# 连接后
EVT  CD 01 01 05 00 52 45 41 44 59 ...     → READY

# 查询版本（SIDE=0）
CMD  CD 01 00 07 00 "VERSION" + CRC
EVT  CD 01 01 ... "VALUE version CDR01v2 firmware 0.1.0"

# 左侧中位（SIDE=1）
CMD  CD 01 01 12 00 "JOINT 90 90 90 200" + CRC
EVT  CD 01 01 ... "[L] OK JOINT started"

# 右侧中位（SIDE=2）
CMD  CD 01 02 12 00 "JOINT 90 90 90 200" + CRC
EVT  CD 01 01 ... "[R] OK JOINT started"

# 双侧停止（SIDE=0）
CMD  CD 01 00 04 00 "STOP" + CRC
EVT  CD 01 01 ... "OK STOP"

# 心跳（每 1s）
EVT  CD 01 02 02 00 "HB" + CRC
```

实际抓取的响应文本（按顺序）：
```
READY
VALUE version CDR01v2 firmware 0.1.0
[L] OK JOINT started
[R] OK JOINT started
OK STOP
HB（每 1s）
```
